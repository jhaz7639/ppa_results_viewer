# FDC Explorer: White Matter in Primary Progressive Aphasia

An interactive companion to the study:

> Hazelton, Chuang, Matis, Quang, Monroe, Piguet, Ballard, & Landin-Romero (2026). *Longitudinal fixel-based analysis reveals degeneration of speech motor white matter networks in nonfluent primary progressive aphasia.* Under review.

## Open the interactive viewer

**https://jhaz7639.github.io/ppa_results_viewer/**

The viewer runs in your web browser; there is nothing to install. It shows the study's white matter results in 3D and as tract-level summaries, in four tabs:

- **Baseline atrophy:** whole-brain differences in fibre density and cross-section (FDC) between groups
- **Longitudinal atrophy:** change in FDC over time within nfvPPA and lvPPA
- **Baseline association:** whole-brain associations between FDC and speech measures
- **Longitudinal association:** tract-level correlations between change in FDC and change in speech

Use a recent version of Chrome, Firefox, Safari or Edge on a laptop or desktop computer. The 3D view needs graphics acceleration (WebGL) to be switched on.

**TIPS**
- Remove background streamlines for a clearer view of the results
- Select "Rotate" to view results in rotation
- Select Bundles from TractSeg to view overall tract location.

## About the data

This repository holds only the files the viewer needs to display **group-level** results. Streamlines are a random subset of the study template tractogram, downsampled for web viewing, and are shown for visualisation only. No individual participant data are included.

Code for the analysis can be found here: **https://github.com/jhaz7639/WM_AOS_PPA**

Please read and agree to the terms of use shown when the viewer opens, and cite the paper when you use or refer to these results.
